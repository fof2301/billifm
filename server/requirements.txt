# Deliberately unpinned lower bounds, not exact pins.
#
# Exact pins bit us: pydantic-core has no prebuilt wheel for Python 3.14, so
# `pip install pydantic==2.10.4` tries to compile Rust and fails. Nobody has time
# for a Rust toolchain at hour 3. Ranges let pip pick a wheel for whatever
# interpreter you have.
#
# Tested on Python 3.13. If you are on 3.14 and hit a build error, use 3.13.

uvicorn[standard]>=0.34
httpx>=0.28
pydantic>=2.10
